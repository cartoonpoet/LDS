<h2 id="overview">개요</h2>

Table Tree는 트리 구조와 표 구조가 같이 필요한 목록 화면용 패턴입니다.
첫 번째 컬럼에 계층을 표현하고, 나머지 컬럼에는 부서/건수/상태 같은 보조 정보를 배치합니다.

<h2 id="supported-features">현재 지원 범위</h2>

- 첫 컬럼 계층 indent
- expanded state 제어
- 다중 컬럼 데이터 표현

<h2 id="usage-guidelines">사용 가이드</h2>

- 조직, 문서 분류, 권한 매트릭스처럼 부모-자식과 속성이 함께 필요한 화면에 적합합니다.
- selection, bulk action, virtualization은 다음 단계 확장 후보입니다.
