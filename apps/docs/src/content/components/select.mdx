<h2 id="overview">개요</h2>

셀렉트는 LDS 폼에서 단일 선택과 제한된 다중 선택을 처리하는 기본 선택 프리미티브입니다.

<FormShowcase />

<h2 id="supported-features">현재 지원 범위</h2>

현재 구현은 아래를 지원합니다.

- 라벨 + caption + helper text
- placeholder
- invalid 상태
- `sm | md | lg` 크기
- single / multiple 모드
- `forwardRef` 기반 폼 연동
- option group 렌더링
- 우측 화살표 위치 고정 정렬

<h2 id="rebuild-notes">재구축 메모</h2>

- `Select`는 새 field foundation과 같은 문맥으로 정리해 Input과 label/helper 구조를 맞췄습니다.
- 아직 native `<select>`를 유지해 접근성과 폼 제출 호환성을 우선 확보합니다.
- searchable / async / command palette형 선택 컴포넌트는 별도 조합형으로 분리할 예정입니다.

<h2 id="dropdown-guidelines">드롭다운 사용 가이드</h2>

- 옵션 수가 적고 탐색 비용이 낮을 때 기본 `Select`를 우선 사용합니다.
- invalid 상태에서는 border, focus ring, helper text가 함께 경고 상태로 보여야 합니다.
- label / caption 분리는 Zeplin form element 패턴처럼 입력의 의미와 보조 설명을 한 줄에서 빠르게 읽게 해줍니다.
- 옵션이 많아지거나 검색이 필요하면 searchable dropdown 같은 조합형 컴포넌트로 분리하는 편이 낫습니다.

<h2 id="integration-notes">적용 메모</h2>

기본 `Select`는 native `<select>`를 유지하므로 접근성과 폼 제출 호환성이 좋습니다.
현재 단계에서는 Input과 같은 foundation을 공유하도록 구조를 정리하는 데 집중했습니다.
