<h2 id="overview">개요</h2>

셀렉트는 LDS 폼에서 단일 선택과 제한된 다중 선택을 처리하는 기본 선택 프리미티브입니다.

<FormShowcase />

<h2 id="supported-features">현재 지원 범위</h2>

현재 구현은 아래를 지원합니다.

- 라벨 + helper text
- placeholder
- invalid 상태
- `sm | md | lg` 크기
- single / multiple 모드
- `forwardRef` 기반 폼 연동
- option group 렌더링

<h2 id="dropdown-guidelines">드롭다운 사용 가이드</h2>

- 옵션 수가 적고 탐색 비용이 낮을 때 기본 `Select`를 우선 사용합니다.
- invalid 상태에서는 border, focus ring, helper text가 함께 경고 상태로 보여야 합니다.
- placeholder는 실제 값이 아니라 안내 텍스트로만 사용합니다.
- 옵션이 많아지거나 검색이 필요하면 searchable dropdown 같은 조합형 컴포넌트로 분리하는 편이 낫습니다.

<h2 id="integration-notes">적용 메모</h2>

기본 `Select`는 native `<select>`를 유지하므로 접근성과 폼 제출 호환성이 좋습니다.
다만 Zeplin의 검색형/복합형 드롭다운은 별도 컴포넌트 범위로 다루는 것이 적절합니다.
