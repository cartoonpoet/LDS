<h2 id="overview">개요</h2>

Data Table은 법무 시스템 목록 화면에서 가장 자주 쓰이는 기본 표 프리미티브입니다.
정렬 가능한 헤더, empty state, 밀도 조절을 우선 지원합니다.

<h2 id="supported-features">현재 지원 범위</h2>

- 정렬 가능한 컬럼 (`sortable`)
- `compact | comfortable` density
- 컬럼별 좌/중/우 정렬
- 비어 있는 상태 메시지
- 캡션과 기본 접근성 속성
- `renderCell` 기반 커스텀 셀 렌더링

<h2 id="usage-guidelines">사용 가이드</h2>

- 기본 목록 화면은 `comfortable`, 데이터 밀도가 높으면 `compact`를 권장합니다.
- 숫자/금액/날짜는 우측 정렬, 상태값은 중앙 정렬이 읽기 좋습니다.
- 복합 셀은 `renderCell`로 구성하되, 정렬값이 별도로 필요하면 `getSortableValue`를 함께 지정합니다.
- 대량 데이터 가상 스크롤, 서버 정렬, row selection은 다음 단계에서 확장하는 편이 안전합니다.
