<h2 id="overview">Overview</h2>

Input은 제목, 식별자, 검색어처럼 **직접 텍스트를 입력해 의미를 생성하는 순간**에 쓰는 기본 필드입니다.
빠른 판단 기준은 단순합니다. 자유 입력이 필요한가, 그리고 입력 상태를 즉시 읽게 해야 하는가입니다.

<DecisionGrid>
  <DecisionCard title="Best for">
    제목, 이름, 코드, 검색어처럼 사용자가 문자열을 직접 입력해야 하는 기본 폼 필드에 적합합니다.
  </DecisionCard>
  <DecisionCard title="Choose when">
    옵션 선택보다 자유 입력이 우선이고, helper text / validation 상태를 함께 보여줘야 할 때 사용합니다.
  </DecisionCard>
  <DecisionCard title="Avoid when">
    허용값이 제한적이거나 검색/추천/마스킹 로직이 핵심이면 조합형 컴포넌트로 분리하는 편이 낫습니다.
  </DecisionCard>
</DecisionGrid>

<h2 id="variants">Variants</h2>

<Checklist
  items={[
    <><code>status</code>: <code>default</code>, <code>success</code>, <code>error</code>로 검증 맥락을 전달합니다.</>,
    <><code>size</code>: <code>sm</code>, <code>md</code>, <code>lg</code>로 화면 밀도에 맞춥니다.</>,
    <>prefix / suffix는 입력 해석을 돕는 경우에만 쓰고, 실제 입력값과 시각 구분이 되도록 유지합니다.</>,
    <>disabled 상태에서도 label / helper는 읽혀야 하므로 정보 계층을 함께 고려합니다.</>
  ]}
/>

<h2 id="usage-guidance">Usage guidance</h2>

<GuidanceGrid>
  <GuidanceCard title="Do">
    검증 실패는 border, focus ring, helper text를 같은 톤으로 맞춰 사용자가 왜 막혔는지 한 번에 읽게 합니다.
  </GuidanceCard>
  <GuidanceCard title="Don't" tone="dont">
    한 필드에 너무 많은 보조 요소를 붙여 입력 영역 자체가 줄어들게 만들지 않습니다.
  </GuidanceCard>
</GuidanceGrid>
