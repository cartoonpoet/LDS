<h2 id="overview">개요</h2>

Tree View는 폴더, 조직, 분류 체계처럼 계층 구조를 한 눈에 탐색할 때 쓰는 기본 프리미티브입니다.
선택 상태와 펼침 상태를 분리해 제어할 수 있도록 설계했습니다.

<h2 id="supported-features">현재 지원 범위</h2>

- 계층형 아이템 렌더링
- controlled / uncontrolled expanded state
- controlled / uncontrolled selected state
- 아이템별 description / meta 슬롯

<h2 id="usage-guidelines">사용 가이드</h2>

- 탐색 중심 UI면 `TreeView`, 행/열 정보가 함께 필요하면 `TableTree`를 우선 고려합니다.
- 선택과 펼침이 항상 같이 움직이지 않아야 하는 화면은 상위에서 상태를 제어하는 편이 안전합니다.
