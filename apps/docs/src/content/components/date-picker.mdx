<h2 id="overview">개요</h2>

Date & Time Picker는 법무 시스템의 조회 기간, 기안일, 예약 시각 입력에 쓰이는 날짜/시간 입력 프리미티브입니다.

<h2 id="supported-features">현재 지원 범위</h2>

- `DatePicker`
- `TimePicker`
- `DateTimePicker`
- `DateRangePicker`
- 공통 label / helper / invalid / size

<h2 id="usage-guidelines">사용 가이드</h2>

- 브라우저 네이티브 입력을 우선 사용해 접근성과 유지보수 비용을 낮춥니다.
- 고급 캘린더 팝오버, preset shortcut, timezone 선택은 다음 단계 확장 후보입니다.
