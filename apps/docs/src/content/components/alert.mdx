<h2 id="overview">Overview</h2>

Alert는 사용자가 **지금 알아야 하는 상태 변화나 주의점**을 짧고 명확하게 전달하는 피드백 컴포넌트입니다.
한 줄 안내로 끝낼지, 액션까지 붙일지 빠르게 결정할 수 있어야 합니다.

<DecisionGrid>
  <DecisionCard title="Best for">
    저장 결과, 정책 안내, 민감 정보 경고처럼 현재 맥락을 끊지 않고 알려야 하는 상태 메시지에 적합합니다.
  </DecisionCard>
  <DecisionCard title="Choose by layout">
    정보만 빠르게 읽히면 <code>default</code>, 액션이나 추가 설명이 붙으면 <code>expanded</code>를 우선 고려합니다.
  </DecisionCard>
  <DecisionCard title="Avoid when">
    사용자의 흐름을 멈추고 강제 결정을 받아야 하는 경우에는 Alert보다 modal/dialog 패턴이 더 적합합니다.
  </DecisionCard>
</DecisionGrid>

<h2 id="when-to-use">When to use</h2>

<Checklist
  items={[
    <>저장 성공, 검토 필요, 민감 조항 탐지처럼 즉시 전달해야 할 상태 변화에 사용합니다.</>,
    <>화면 컨텍스트를 유지한 채 짧은 설명과 가벼운 액션을 함께 노출할 때 적합합니다.</>,
    <>닫기 버튼만 필요한 경우에는 가장 가벼운 default 조합을 우선 사용합니다.</>
  ]}
/>

<h2 id="variants">Variants</h2>

<Checklist
  items={[
    <><code>type</code>: <code>info</code>, <code>confirm</code>, <code>saveTemporarily</code>, <code>secret</code>로 의미 축을 나눕니다.</>,
    <><code>size</code>: <code>medium</code>, <code>small</code>로 밀도를 조절합니다.</>,
    <><code>layout</code>: <code>default</code>, <code>expanded</code>로 정보량과 액션 수를 분리합니다.</>,
    <>액션 축은 <code>action</code>, <code>secondaryAction</code>, <code>textAction</code>, <code>showCloseButton</code> 조합으로 확장합니다.</>
  ]}
/>

<h2 id="usage-guidance">Usage guidance</h2>

<GuidanceGrid>
  <GuidanceCard title="Do">
    버튼이 없고 빠르게 닫을 수 있어야 하는 안내는 닫기 버튼만 있는 조합으로 최대한 가볍게 유지합니다.
  </GuidanceCard>
  <GuidanceCard title="Don't" tone="dont">
    여러 액션을 좁은 행형 Alert 안에 억지로 밀어 넣어 메시지 가독성을 해치지 않습니다.
  </GuidanceCard>
</GuidanceGrid>

<Callout title="Current implementation target" tone="success">
  현재 1차 픽셀 기준점은 <code>info + medium + default + close button</code> 조합입니다. 이 기준을 먼저 정확히 맞춘 뒤 나머지 축을 같은 구조에서 확장합니다.
</Callout>
