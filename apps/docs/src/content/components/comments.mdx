<h2 id="overview">개요</h2>

Comments는 문서 검토 이력, 협업 대화, 모바일 하단 시트 안의 피드백 흐름처럼
서로 비슷하지만 레이아웃이 다른 코멘트 패턴을 하나의 기준으로 묶은 컴포넌트입니다.

<h2 id="supported-features">현재 지원 범위</h2>

- `timeline` / `chat` / `bottom-sheet` 변형
- 작성자, 시각, 메타 정보, 첨부 표시
- 내가 남긴 메시지 정렬 처리
- controlled / uncontrolled composer state
- 제출 시 trim 처리와 자동 초기화

<h2 id="usage-guidelines">사용 가이드</h2>

- 문서 검토 로그처럼 순서와 맥락이 중요하면 `timeline`을 사용합니다.
- 담당자 간 빠른 왕복 커뮤니케이션은 `chat` 변형이 더 읽기 쉽습니다.
- 모바일 상세 화면이나 하단 레이어 안의 의견 흐름은 `bottom-sheet` 변형이 적합합니다.
- 코멘트 데이터 fetch, optimistic update, 권한 제어는 상위 컨테이너에서 담당하고,
  컴포넌트는 목록 렌더링과 composer 인터랙션에 집중시키는 편이 유지보수에 유리합니다.
